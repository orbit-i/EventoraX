# ADR-001: Use flat JSON files as placeholder storage

## Status
Accepted (temporary — superseded once MySQL schema is finalized)

## Context

This module needed to persist certificates, tickets, and ID cards from
the start of development, but the real MySQL schema (owned by Mehwish)
was not yet finalized. Waiting for it would have blocked all progress.

## Decision

Store all records in flat JSON files on local disk, accessed through
small dedicated modules exposing simple functions: save, readAll,
update, findBy.

## Consequences

- Positive: unblocked all backend development immediately
- Positive: swapping to a real database later only requires rewriting
  these small data modules, not the routes layer
- Negative: not suitable for production, no concurrency safety, no
  relational integrity
- Action required: migrate to MySQL once Mehwish's schema is finalized
