# EventoraX product guide

EventoraX helps universities, societies and organizations run events from start to finish: publish an event, take
registrations, send QR tickets, check people in at the door, issue certificates anyone can verify, print ID cards and see
how it all went.

This guide explains every page in plain language. You don't need any technical knowledge.
The pictures come from the demo organization "Margalla University Computer Society".

## Who are you?

| You are… | What you do in EventoraX | Start here |
|---|---|---|
| **Attendee** (anyone, no account) | Register for events, get your QR ticket, check a certificate | [Public pages](01-public-pages.md) |
| **Organization admin** | Run your organization: events, team, settings, billing | [Getting started](02-getting-started.md), then every chapter |
| **Manager** | Create and run events, attendees and certificates | [Getting started](02-getting-started.md), chapters 3–7 |
| **Viewer** | Look at everything, change nothing (for example a faculty advisor) | [Getting started](02-getting-started.md) |
| **Superadmin** (the EventoraX team) | Run the whole platform: organizations, payments, plans, settings | [Superadmin panel](10-superadmin.md) |

## Words used in this guide

| Word | Meaning |
|---|---|
| **Organization** | Your university society, department or company on EventoraX. Its data is private to its team. |
| **Status of an event** | **Draft** (only your team sees it), **Upcoming** (published, people can register), **Active** (happening now), **Completed** (over), **Archived** (put away, can be restored). |
| **Mode** | **Physical** (in person), **Online** or **Hybrid** (both). |
| **Registration status** | **Registered**, **Attended** (was there), **Absent** (didn't come, keeps the seat), **Cancelled** (frees the seat). |
| **Category** | A group of attendees you define per event, for example VIP, Student or Speaker. Printed on tickets, ID cards and certificates. |
| **Verify code** | The code on every certificate, like `EVX-CZBQ-7ZAX`. Anyone can check it on the website. |
| **PKR** | All prices are in Pakistani rupees. |
